# 追加仕様 v1.3 反映内容

更新日: 2026年10月21日。基本仕様 v1.1 に適用し、v1.2 の追加内容を統合します。
ユーザー提示の統合版仕様に基づき、以下を実装します。記載のない MFT・USN 索引、保存・復旧、4列のソート、DnD、トレイ常駐は維持します。

## 検索

結果はファイルだけです。フォルダの名前・内部ID・親IDは索引に残し、階層条件をメモリ内で評価します（SR-10～13）。
比較はすべて大文字・小文字を区別しません。
2026年10月23日の変更により、フォルダ指定の有無にかかわらず、ファイル名条件は部分一致とします。

| 入力 | 最初のフォルダ | 中間フォルダ | ファイル名 |
|---|---|---|---|
| `file` | なし | なし | 部分一致 |
| `dir/file` | 後方一致 | なし | 部分一致 |
| `dir/sub/file` | 後方一致 | 完全一致 | 部分一致 |
| `/dir/sub/file` | 完全一致 | 完全一致 | 部分一致 |

フォルダ条件は連続した階層で、最後のフォルダが直接の親です。先頭 `/` はルート指定ではありません。
`var/data/repo` は `C:\work\myvar\data\repository.cs`、`C:\var\data\myreport.xlsx` に一致し、`var\other\data\report.xlsx`、`var\database\report.xlsx` には一致しません。
`/var/data/repo` は `C:\work\var\data\repository.cs` に一致し、`myvar\data\report.xlsx` には一致しません。

未規定の境界入力は次のように固定します。

- 空文字・`/` 単体は結果なし。
- 中間の空フォルダ（`dir//file`）は不一致。
- 末尾 `/` は空のファイル名条件として、そのフォルダ直下の全ファイル。
- `/file` はフォルダ指定なしのファイル名部分一致。
- 空白を除去せず、`\` を検索構文の区切りに変換しない。

## 操作とシェル

| 要件 | 反映内容 |
|---|---|
| HK-01～07 | RegisterHotKey による Win + /、表示・前面化・フォーカス、常駐中の有効性、終了時解除、登録失敗時の通知・ログとトレイ操作継続。起動時のキーボード配列で `/` を仮想キーに変換。 |
| KB-01～08 | 入力で検索、検索欄の ↓ で先頭行、1件もなければそのまま。通常の上下移動、先頭行の ↑ と一覧の `/` で検索欄へ戻る。Enter で現在のファイルを開く。 |
| フォーカス | 検索文字列を保持し、`/` を追加しない。フォーカスだけでは再検索しない。選択行を着色。 |
| OP-01～06 | 修飾キーなしの左クリックまたは Enter で Shell の既定アプリに委譲。消失・アクセス不可・関連付けエラーは通知して検索を継続。 |
| クリックと DnD | 押下・移動・解放を区別し、ドラッグ開始後とキャンセル後は開かない。Ctrl / Shift クリックは選択操作として開かない。 |
| CM-01～05 | 右クリックした単一ファイルに対する IShellItem / IContextMenu・2・3 の従来形式メニュー。描画・サブメニューのメッセージを転送し、実行は Shell に委譲。操作終了後に COM・メニュー・フックを解放。 |

## 描画・メモリ

アプリ生成時に `RenderOptions.ProcessRenderMode = RenderMode.SoftwareOnly` を設定します（RD-01～04）。
切り替え機能は設けません。検索エンジンは WPF に依存しません。

- MEM-01～03: 索引と表示を分離し、不変スナップショットの共有で更新と検索を両立。索引はID順の分割配列とし、変更区画だけを複製。ファイル名・属性・親IDを索引に保持し、名前と検索中の親パスは共有。
- MEM-04～06: 行・列を仮想化。結果はデータだけで、全件分の WPF 行を作らない。新しい入力・非表示・最小化・終了時に不要な結果参照を解放。
- MEM-07～08: 非表示中は UI への索引・ステータス通知を停止。現在の索引のみを維持し、復帰時は保存した検索条件で再検索。アイドル時の Journal は1秒間隔で確認し、変更がなければ再読込・検索を行わない。
- MEM-09～10: `--measure-memory` で Private Bytes を主指標として、索引件数・表示結果件数・生成済み行数・状態を CSV に記録。

計測状態は起動直後、索引完成、検索中、大量結果表示、トレイ常駐、5分ごとの継続稼働サンプルです。
上限値は実データの件数・測定後に決定します。合成索引の回帰プロファイルと実プロセスの計測は区別します。
測定方法は README、受入確認は `acceptance.md`、実際の検証範囲は `validation.md` を参照してください。
