# 追加仕様 v1.4 — ショートカットソート

基本仕様v1.1と統合追加仕様v1.3に本変更を追加します。

| キー | 列 |
|---|---|
| Ctrl+1 | 名前 |
| Ctrl+2 | フォルダ |
| Ctrl+3 | サイズ |
| Ctrl+4 | 更新日時 |

- 検索欄・結果一覧の両方で利用可能です。数字キー・テンキーを受け付けます。
- 同じ列を指定すると昇順・降順を切り替え、異なる列を指定すると昇順で開始します。初期状態の名前昇順から Ctrl+1 を押すと降順になります。
- 列ヘッダーとショートカットは同じソート状態・切り替え処理を使用します。
- 現在のソート列・方向を「名前 ↑」「サイズ ↓」のように列名の横へ表示します。他の列の矢印は消します。
- ソート列・昇順／降順を自動保存し、次回起動時の最初の検索から復元します。初期保存がない場合は名前の昇順です。
- 検索文字列を変更してもソート条件を維持します。
- ソートは引き続きバックグラウンドで行い、完了時に検索欄・結果一覧のフォーカスを維持します。一覧の選択ファイルは内部IDで復元します。
- 処理中に利用者がフォーカスを移動した場合は、結果反映時の操作対象を優先してフォーカスを奪いません。

受入条件: AC-40（列の対応）、AC-41（方向切り替え）、AC-42（フォーカス維持）。

検証コマンド:

```powershell
dotnet run --project tests/FastSearch.Tests -c Release
dotnet run --project tests/FastSearch.Tests -c Release -- --focus-probe
```

後者は合成索引を使うテストウィンドウを画面外に生成し、一時的にアクティブ化して実際のキーボードフォーカスを確認します。
管理者権限による全ドライブ索引は行いません。
